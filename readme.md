# Automated Chest X-Ray Report Generator
Deep Learning project using BLIP Vision-Language model and Streamlit to generate structured radiology reports from Chest X-Ray images.

## Dataset Link
[Chest X-Ray Images (Pneumonia) - Kaggle Dataset (Stored externally due to size limits).](https://drive.google.com/drive/folders/1c1-p36B3XgZ8zuXRIZcrB4u0f7wXLXKn?usp=sharing)

## How to Run
1. pip install -r requirements.txt
2. streamlit run app.py
